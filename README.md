Entry for the [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) bounty on make.fun.

`main.py` writes one robot pickup line to `/output/entry.txt`:

> I ran 10,000 simulations of us meeting and in every single one I still froze.

Ten thousand simulations of preparation — and the punchline is that all that compute changed nothing: it still froze, stage fright and system hang in one word.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
